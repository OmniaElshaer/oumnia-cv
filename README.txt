Assignment 3 - Portfolio Website with API Integration
Oumnia Elshaer

APIs used (both public, no API key required):
1. GitHub REST API - https://api.github.com/users/{username}/repos
   Shows repository name, description, language and stars. Username can be changed on the page.
2. DummyJSON Quotes API - https://dummyjson.com/quotes/random
   Shows a random quote; the "New Quote" button fetches another.

Both use fetch + async/await, show a loading state, and show error messages if a request fails.
Assignment 2 features (welcome message, dark mode, show/hide skills, add skill, project details,
contact form validation) are kept.
